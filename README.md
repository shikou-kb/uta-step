# 歌で、一歩 · 日语逐句跟唱

面向日语零基础的歌曲学习网页，适配手机、平板与电脑。

## 学习方式

- 点击歌词直接定位到当前句，支持听完暂停、单句循环、留白跟唱和整曲连播。
- 假名、罗马音与中文译文可以独立开关；支持 0.6–1.1 倍速。
- 86 个分句均有词语、句型、标准例句和发音提示。
- 手机底部提供“跟唱 / 选句 / 讲解 / 离线”快捷入口。
- 学习记录只保存在当前设备的浏览器，可通过 JSON 备份转移。

## 手机与离线使用

1. 在手机浏览器打开网站。
2. 点“离线”或“路上学习”，联网准备约 8 MB 音频。
3. 确认显示“音频与页面已备齐”。
4. 安卓可在 Chrome/Edge 菜单中添加到主屏幕；iPhone 可在 Safari 的分享菜单中添加到主屏幕。
5. 出门前开启飞行模式，重新打开并试听一句，确认当前设备能够离线使用。

浏览器可能自动清理缓存，离线资源不是永久备份。单句循环与留白跟唱建议保持前台；锁屏后手机可能暂停计时。

## 发布

纯静态网站，不需要安装依赖或构建。GitHub Pages 使用 `main` 分支根目录发布。所有资源使用相对路径，适配项目站点子目录。

`sw.js` 只管理本网站范围内的缓存，音频必须由用户点击按钮后才完整缓存。离线音频支持 HTTP Range 请求。
